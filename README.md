# NLP Mini Projects 🚀

This repository contains two natural Language Processing (NLP) projects:

1. Sentiment Analysis (Positive / Neutral / Negative)
2. Question Answering using BERT

---

# 1️.Sentiment Analysis 

## Overview
A simple sentiment classification model that predicts whether a given text is:
- Positive 
- Neutral   
- Negative   

---

# 2️.BERT Question Answering 

## Overview
A QA system using a pre-trained BERT model that extracts answers from a given context.
